# Changelog

All notable changes to this project will be documented here.

## 0.1.0 — local candidate

- Added strict versioned manifest parsing with fail-closed path, size, status, and ID validation.
- Added deterministic PG001–PG008 evaluation and JSON/Markdown receipts.
- Added responsive React maintainer console with safe draft reset and stale-PASS clearing.
- Added CLI with stable exit codes and explicit receipt outputs.
- Added tokenless local GitHub Action entrypoint with workspace-confined paths.
- Added automatic pull-request event parsing, validated merge-base Git diff collection, generated manifests, repository evidence policy, and escaped workflow annotations.
- Added unit, UI, CLI smoke, manual Action smoke, and temporary-repository auto-mode smoke gates.
- Added least-privilege pinned-SHA workflow example with full checkout history, disabled credential persistence, and security documentation.
